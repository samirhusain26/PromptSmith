How It Works

Usage

Important: You must configure either an API key or on-device AI for the extension to work.

  • Open ChatGPT, Claude, or Gemini.
  • Look for the PromptSmith Sparkle button.
  • Select a persona to instantly refine your prompt.

Cloud API Setup

Fast and reliable. Both providers have generous free tiers—you are unlikely to hit rate limits or incur costs.

  • Groq: No credit card required.
  • Gemini: May require a credit card on file.
  1. Get an API Key from your chosen provider.
  2. Paste the key in the "Cloud Provider" section below.
  3. Click Save.
  4. Select a model from the dropdown if you need to customize (defaults are the most cost-effective options).

Local (Nano) Setup

Privacy-first option. Runs offline in Chrome.

  1. Open chrome://flags
  2. Enable Optimization Guide On Device Model
  3. Enable Prompt API for Gemini Nano
  4. Relaunch Chrome.
  5. Open chrome://components and check for updates to "Optimization Guide On Device Model".
Note: Works on Google Chrome. May not work on other Chromium browsers (Brave, Edge, etc). If using those, please use the Cloud API instead.

📋 Setup Instructions

  1. Open chrome://flags/#optimization-guide-on-device-model
  2. Set "Optimization Guide On Device Model" to Enabled BypassPerfRequirement
  3. Open chrome://flags/#prompt-api-for-gemini-nano

  5. Relaunch Chrome
  6. Open chrome://components and click Check for update on "Optimization Guide On Device Model"
