How It Works

⚡ 1. Local (Nano)

The privacy-first choice. Runs offline in Chrome.

  1. Open chrome://flags (copy url)
  2. Enable Optimization Guide On Device Model
  3. Enable Prompt API for Gemini Nano
  4. Relaunch Chrome.
  5. Open chrome://components and check for updates to "Optimization Guide On Device Model".

☁️ 2. Cloud (Flash)

Reliable fallback if your device doesn't support Nano.

  1. Get a free API Key from Google AI Studio.
  2. Paste the key in the "Google API Key" section above.
  3. Click Save.

🌐 3. WebLLM

Private, powerful AI running in your browser via WebGPU.

  1. Go to the WebLLM section above.
  2. Click Download Model (~600MB).
  3. Wait for the progress to complete once.

✨ Usage

Once tailored:

  • Open ChatGPT, Claude, or Gemini.
  • Look for the PromptSmith Sparkle button.
  • Select a persona (e.g., "Architect") to instantly refine your prompt.
