How It Works

Usage

Important: You must configure either an API key or on-device AI for the extension to work.

  • Open ChatGPT, Claude, or Gemini.
  • Look for the PromptSmith Sparkle button.
  • Select a persona to instantly refine your prompt.

Cloud API Setup

Fast and reliable. Requires an API key.

  1. Get a free API Key from Google AI Studio.
  2. Paste the key in the "Google API Key" section below.
  3. Click Save.

Local (Nano) Setup

Privacy-first option. Runs offline in Chrome.

  1. Open chrome://flags (copy url)
  2. Enable Optimization Guide On Device Model
  3. Enable Prompt API for Gemini Nano
  4. Relaunch Chrome.
  5. Open chrome://components and check for updates to "Optimization Guide On Device Model".
